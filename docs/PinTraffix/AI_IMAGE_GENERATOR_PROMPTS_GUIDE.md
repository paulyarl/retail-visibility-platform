## 1. AI Generation Principles & Technical Parameters

### 1.1 Generation Strategy: AI Backgrounds + Canva Compositing

To achieve highest conversion on Pinterest, visual assets combine:
1. **AI-Generated Base Visuals**: High-end retail interiors, modern device mockups, split-screen background textures, before/after photography, and abstract tech flows.
2. **Real UI Screenshots**: Screen grabs from staged Visible Shelf demo tenants and POS systems.
3. **Canva Overlays**: Typography (Pin headline, value prop, price badge), logo, and CTA buttons added during final assembly at 1200x1800 (2:3 aspect ratio).

### 1.2 Aspect Ratios & Technical Parameters

| Platform / Tool | Parameter / Format | Target Resolution |
|---|---|---|
| **Midjourney v6/v6.1** | `--ar 2:3 --v 6.1 --style raw --q 2` | 1200 × 1800 px (scaled in Canva) |
| **Flux.1 (Dev/Schnell)** | Aspect ratio `2:3` or resolution `800x1200` | 1200 × 1800 px |
| **DALL-E 3** | `size: "1024x1792"` (Vertical) | 1200 × 1800 px |
| **Ideogram 2.0** | Aspect ratio `2:3`, Style: `Design` or `Realistic` | 1200 × 1800 px |

### 1.3 General Style & Color Palette

- **Brand Aesthetic**: Clean, modern SaaS / Retail technology. Warm boutique retail interiors paired with sleek digital UI interfaces.
- **Lighting**: Soft studio lighting, bright natural light in retail scenes, neon accent glows (blue `#2563EB`, amber `#F59E0B`, emerald `#10B981`) for digital tech overlays.
- **Composition**: Keep top 30% and bottom 20% uncluttered for typography and CTA banners added in Canva.

### 1.4 QR Code Post-Render Canva Assembly & Standard Placement Rule

- **Do Not AI-Render QR Patterns**: AI image generators (Midjourney, DALL-E 3) render scrambled, un-scannable QR patterns. Prompts must instruct the generator to render **clean, framed, blank white or light grey placeholder slots** on shelf tags, window decals, flyers, or UI cards.
- **Canva Assembly**: Real, scannable, styled QR codes generated by Visible Shelf's native `storefront_qr` capability (`generateStyledQRCode` / `qr-style-config.ts`) are dropped into these placeholder slots during Canva editing.
- **Standard Platform QR Placement**: Every Pin template across all loops reserves a **standard placement spot** (bottom-right or bottom-left corner with a small "Scan to View Live Demo" badge) containing a real scannable QR code that links directly to the public demo surface on Visible Shelf.

## 5. Master Prompt Execution Workflow & Tool Cheat Sheet

### 5.1 Tool Selection Matrix

- **Midjourney v6.1**: Best for realistic retail store interiors, product flat-lays, lifestyle photography, and high-end 3D renders.
- **Ideogram 2.0**: Best when you want AI to render crisp, legible text directly into the image (e.g. badges like "$29/mo" or "20% OFF").
- **Flux.1 (Dev)**: Best for hyper-realistic lighting and complex device mockups with smooth UI screen integration.
- **DALL-E 3 (via ChatGPT Plus)**: Best for fast concept exploration and precise prompt adherence for multi-element diagrams.

### 5.2 Step-by-Step Prompt to Canva Workflow

1. **Generate Image**: Run the prompt in Midjourney or Flux with `--ar 2:3`.
2. **Upscale**: Export the generated image at 2000px+ height.
3. **Import to Canva**: Load the image into the 1200x1800 px Pin template in Canva.
4. **Overlay UI Screenshots**: Paste actual high-res screenshots from the Visible Shelf demo environment over screen placeholders if needed.
5. **Apply Typography**:
   - **Headline**: Montserrat / Inter Bold, 64–84pt, high contrast background panel or drop shadow.
   - **Sub-headline**: 32–42pt, clear value proposition.
   - **Badge**: Price or offer pill badge (e.g., "14-Day Free Trial" or "$59/mo").
6. **Export**: Export as WebP and PNG to `apps/web/public/images/pinterest/<asset-filename>.png`.
7. **Code Swap**: Update `heroImage` in the relevant `page.tsx` file and run `pnpm checkweb`.
