## 1. Strategic Frame

### The Core Mission

Visible Shelf exists to move **local retailers from real-time product discovery to purchase conversion** without forcing them to build an IT department. The V2 model aligns tiers with business models, not feature accumulation, which makes the platform unusually easy to explain to a Pinterest audience of overwhelmed, non-technical retail owners.

### Why Pinterest First

- Pinterest is a **search-and-planning engine**, not a social feed. Small retail owners search for solutions ("get my store on Google", "Clover POS marketing", "local business online presence") before they buy.
- The visual format matches platform outputs: storefront pages, product grids, QR codes, directory listings, Google Shopping placements.
- Buyer intent is high when the searcher is in the problem-solving or business-building phase.
- Pinterest content compounds over time, which fits a tier-upgradation SaaS model where a single pin can keep capturing intent for months.

### PinTraffix Method Applied

A **sales loop** for Visible Shelf is a five-stage path:

1. **Search phrase** — what a retailer types.
2. **Pin angle** — why they should stop scrolling.
3. **Click reason** — the immediate value they expect.
4. **Destination** — the page that continues the same promise.
5. **Offer** — the tier or trial that makes the next action logical.

The goal is not a direct sale on Pinterest. The goal is a **relevant, low-friction trial start** that matches the merchant's current business reality.

## 11. Pinterest CTA Destination Surface Readiness

### 11.1 What the First Draft Missed

The original analysis treated the "destination" stage as a conceptual landing page. It did not tie each sales loop to an **actual platform route** or audit whether those routes are optimized for a Pinterest click. This section corrects that by inventorying real surfaces, scoring CTA readiness, and assigning the specific optimization work that must happen before traffic is sent.

### 11.2 Platform Surface Inventory

The platform has public, merchant, and directory surfaces. Only a subset are ready to receive Pinterest traffic today.

| Route | Surface Type | Metadata / OG State | CTA Readiness | Best Pinterest Use |
|---|---|---|---|---|
| `/` (`/(platform)/page.tsx`) | Platform home / dashboard hybrid | `'use client'`, no `generateMetadata` or OG tags | **Low** — mixed marketing + authenticated dashboard, no preview control | Not recommended until split |
| `/features` | Feature showcase | `'use client'`, no `generateMetadata` or OG tags | **Low** — visual but not Pinnable | Capability-aware Pins after metadata + CTA pass |
| `/tenant/[id]` | Public merchant storefront | `generateMetadata` + `openGraph` + schema.org | **High** — good preview; needs image/tracking tuning | Shop/store-level Pins, social proof, QR angles |
| `/products/[id]` | Public product detail | `generateMetadata` + `openGraph` (product images) | **High** — best Pinnable surface | Product Pins, shoppable content |
| `/directory/[slug]` | Directory store listing | `'use client'`, no `generateMetadata` or OG tags | **Low** — link previews will be generic or blank | Directory discovery Pins after metadata pass |
| `/directory`, `/directory/stores`, `/directory/categories` | Directory index / browse | Likely `'use client'`, no route-level OG | **Low** | Category/seasonal boards after rebuild |
| `/checkout`, `/cart/[tenantId]` | Transactional | n/a | **Not a CTA destination** | Never use as a Pinterest landing surface |
| `/auth/signup`, `/auth/signin` | Authentication | Minimal metadata | **Medium** | Only as a hard conversion step from a qualified landing page |

### 11.3 Surface-by-Surface Optimization Recommendations

#### 11.3.1 Platform Home (`/`)
- **Issue:** `/(platform)/page.tsx` is a 1,200+ line `'use client'` page that renders both marketing hero and authenticated dashboard. It cannot emit server-side `metadata` or `openGraph`.
- **Required fix:** Split into two route-level components per the existing UX audit recommendation:
  - `app/(platform)/page.tsx` → authenticated dashboard only.
  - `app/landing/page.tsx` or `/` → public marketing page with `generateMetadata`, hero CTA, and Pinterest OG image.
- **Pinterest-specific work:**

### 11.6 What Happens If You Skip This

- **Bounce:** A Pin promising "See how deposit checkout works" that lands on a generic homepage loses the loop.
- **No link preview:** Pinterest users will not save or click a link with a blank or off-brand preview.
- **Trial drop-off:** Traffic that reaches `/auth/signup` without context converts at a fraction of the rate of message-matched landing pages.
- **Attribution loss:** Without UTM/ref capture, you cannot tell which board, angle, or loop produced the trial.
